# Stankogram
## Мессенджер университета МГТУ СТАНКИН

### Медиа в чатах

Фото и видео лежат во внешнем S3-совместимом хранилище. Бакет **приватный**: браузер
льёт и качает файлы напрямую у провайдера по подписанным ссылкам, которые API выдаёт
только участникам чата. Трафик медиа через сервер не идёт.

Эндпоинт, регион, имя бакета и стиль адресации лежат открыто в
`server/src/server/config.py` — они всё равно видны в каждой подписанной ссылке.
Секретами остаются только ключи, они приходят из `.env`:

```sh
S3_ACCESS_KEY_ID=...
S3_SECRET_ACCESS_KEY=...
```

Разовая проверка доступа и настройка CORS на бакете (без CORS браузер не сможет
загружать файлы):

```sh
docker compose exec server uv run s3_setup https://stankogram.ru http://localhost:5173
```

Брошенные загрузки (файл выбрали, но сообщение не отправили) удаляются через сутки:

```sh
docker compose exec server uv run cleanup_attachments
```
